# Research workflow safeguards

The user approved improving the audited LangGraph workflow. Preserve Phase 2A scheduling semantics and the independent feasibility checkers. Do not implement AGV, transport, RL, GNN, or maintenance optimization.

Deliver conservative literature classification and explicitly unverified offline extraction; visible provider failures/degradation; immutable foundation, innovation, and graduation requirements; separate execution, evidence, feasibility, performance, and research acceptance statuses; bounded generated-code execution; strict benchmark coverage; and reproducible CLI/documentation/dependencies.

Innovation means the proposal's production/logistics/DRL deliverables. Graduation means parallel machines, due dates, maintenance windows/timing, total tardiness, and fixed-versus-joint maintenance comparison. The existing static evaluator cannot certify either research target. These profiles describe future requirements and do not authorize later-stage implementation. Offline/template experiments must never be presented as verified paper extraction or research completion.

Acceptance: regression tests reproduce the audit failures before fixes; provider outage fails visibly unless fallback is explicitly enabled; unverified formulas have no asserted paper attribution; missing required benchmarks fail; generated code cannot change the reference instance and is terminated on timeout; per-track reports show unmet requirements; all existing scheduling tests and coverage >=80% pass.
