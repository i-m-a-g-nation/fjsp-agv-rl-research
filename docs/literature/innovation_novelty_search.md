## 3. 结论

**已被占据，不能再主张的说法**：
1. "首次用 DRL 处理有限缓冲的柔性作业车间"：Zhang 等 2026 已明确这样声称，不过他们的模型没有运输。
2. "首次用 DRL 处理有限资源与死锁的柔性制造系统"：Hu 等 2020 的 Petri 网 + DQN 已经做了，且被引很多。
3. "首次做机器与 AGV 的联合 DRL 调度"或"动态 FJSP-AGV 的 DRL"：2023–2026 年已有大量论文。
4. "首次研究缓冲容量对机器 + AGV 调度的影响"：1990 年代的 FMS 研究已用规则和束搜索做过灵敏度分析。

**这一轮没有发现的组合（可作为创新点，但要收窄表述）**：
- **主创新点**：在 FJSPT 建模框架下，即 AGV 有位置、空驶和载货行驶分别计时、首末运输到 L/U 站，
  引入**有限输入缓冲 + 加工后阻塞 + 死锁处理**，并用 DRL 求解。
  - FJSPT 一线的 DRL 论文都假设缓冲无限（Link 2026、HA-DQN 2025、Wang 2024）；
  - 有限缓冲的 DRL 论文没有运输（Zhang 2026）；
  - Petri 网一线把运输抽象为资源，对空驶和行驶时间的建模方式没能核实（Hu 2020）。
- **次创新点**：在 DRL 设定下研究**缓冲越紧张，联合决策与解耦决策的差距如何变化**。
  - Link 2026 只在缓冲无限的作业车间里变化了运输资源紧张度；
  - 旧的 FMS 研究分析过缓冲容量，但没有用学习方法，也没有做联合与解耦的对比。

**创新性等级**：组合式、增量式创新。只要实验扎实，足以支撑大创结题和一篇 EI 会议或中文核心论文；
冲击高水平期刊需要更强的方法创新或更有说服力的结果，目前无法保证。

**写论文时必须引用并区分的近邻工作**：Hu 2020、Zhang 2026、Link 2026、Zhuang 2025、HA-DQN 2025，
以及 Petri 网 + DRL 一线（Lassoued 2025、He 2026）。审稿人很可能熟悉 Hu 2020。

## 4. 对建模决策的影响

- 原建议（有限输入缓冲、加工后阻塞、派车时预留、检测死锁）不需要改，它正好落在上面的空档里。
- 死锁处理要与 Petri 网一线区分：本项目用"派车时预留缓冲位"的动作掩码，加上仿真检测，
  不建 Petri 网。相关工作一节要说明这样选择的理由：直接沿用 FJSPT 的时间模型和基准算例，
  便于与 FJSPT 一线的 DRL 和 CP 结果比较。
- 必须做 B = ∞ 的对照，证明在缓冲无限时，本项目的方法与 FJSPT 一线的结果在同一水平。

**第二轮结论**：

1. 没有发现同时具备"柔性作业车间（柔性路线）+ AGV 显式行驶 + 有限缓冲或阻塞 + 深度强化学习"的论文。
   **原主创新点仍然成立，但空档比第一轮判断的更窄**：
   - A 类说明问题已有人建模，用的是元启发式；
   - B 类说明"DRL + 运输 + 阻塞"在流水车间类问题上已有 2025–2026 年的中文期刊论文。

   本课题的贡献只能表述为"把 DRL 推广到带 AGV 运输和有限缓冲的**柔性**作业车间"，属于增量式贡献。
   相关工作一节必须引用 A、B 两类，并说明区别：柔性路线使机器选择和运输目的地在决策时才确定，
   这与固定路线的流水车间不同。
2. "缓冲越紧张时，联合决策与解耦决策差距如何变化"的分析，两轮检索都没有发现，可作为同等重要的创新点。
3. 第一轮的检索建议（学位论文常先出现）得到印证：A 类的直接相关工作主要是硕士论文。

**建议的论文贡献表述**（按重要性排列）：
1. 建立带有限输入缓冲、加工后阻塞和 AGV 显式行驶的柔性作业车间调度模型，配有独立检查器和小规模精确参考（CP-SAT）；
2. 提出考虑缓冲预留的动作掩码与深度强化学习求解方法；
3. 分析缓冲容量对"联合与解耦决策差距"的影响；
4. 公开环境与算例。可复现的基准本身有价值，参考 Lassoued 2025 提供的 gym 环境。
