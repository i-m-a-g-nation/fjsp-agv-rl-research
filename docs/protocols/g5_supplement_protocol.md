## 5. 评价方法

每个测试实例上：

| 方法 | 设置 |
|---|---|
| EDD、MDD、ATC | 一次构造 |
| IGA | 一次 10 s 运行（种子 0），记录 best-so-far 轨迹 |
| SA | 每个时间预算单独运行一次（其降温依赖预算），种子 0 |
| RL（3 个种子各一个模型） | 贪心 1 次，再采样 4、16、64 次（GPU 计时，同 G4）；另报单线程 CPU 的贪心与采样 4 次 |
| 只模仿（3 个种子） | 贪心 1 次，采样 16 次 |
| **RL + IGA**（E3，3 个种子） | 先用该种子的 RL 做贪心 + 采样 16 次，把其中互不相同的序列（最多 40 个，即种群规模）放入 IGA 初始种群，其余个体按 IGA 原方式生成；IGA 运行到总时长 10 s。轨迹时间 = RL 推理时间 + IGA 已用时间 |
| CP-SAT | 只用于 G5-T 的 n = 20 实例，60 s |

- **任一时间预算 t 下的取值**：沿用 G4 的定义（`g9_g4_summary.py`）。RL 取在 t 之前完成的各个推理点的最好值；
  搜索方法取轨迹中 t 之前的最好值；t 之前尚未得到解的记为"无解"，不参与该点的配对检验。
- **时间预算**：t ∈ {0.05, 0.1, 0.2, 0.5, 1, 2, 5, 10} s。
- **best-known**：每个实例取所有方法、所有种子、所有运行中的最小总延期；
  gap = (T − T\*) / max(1, T\*)。
- **计时口径**（同 G4）：
  - 搜索方法：单实例、单进程 CPU，2 个进程并行，本机无其他负载；
  - RL：一次一个实例，计入特征计算、环境步进和最终检查。
- 所有调度都过检查器，被拒绝的结果直接终止实验。

## 6. 预先登记的假设

按训练种子分别检验：单侧配对 Wilcoxon 符号秩检验；每个种子内对 H1–H5 做 Holm 校正，α = 0.05；
**3 个种子中至少 2 个满足即成立**。

| 编号 | 假设 | 测试集与时间 |
|---|---|---|
| **H1**（复现 G4 的探索性发现） | RL 的 gap 小于 IGA | G5-T，n = 100，t = 1 s |
| **H2**（REINFORCE 的作用） | RL 贪心的总延期小于只模仿模型的贪心 | G5-T 全部 576 个实例 |
| **H3**（热启动，长预算） | RL + IGA 的 gap 小于 IGA | G5-T 全部实例，t = 10 s |
| **H4**（热启动，短预算） | RL + IGA 的 gap 小于 IGA | G5-T 全部实例，t = 1 s |
| **H5**（规模推广） | RL 的 gap 小于 IGA | G5-L，t = 2 s |

**描述性结果**（不做检验）：
- 各方法按规模的质量—时间曲线，3 个种子分别画出；
- 种子之间的差异：每个时间预算下 3 个种子 gap 的极差；
- 只模仿与 RL 在不同采样次数下的差距；
- RL + IGA 与纯 RL、纯 IGA、SA 按规模比较，尤其是 n = 20；
- G5-L 上各方法在各时间预算下的 gap 与"无解"比例（n = 200 时 RL 的单次推理可能超过 0.2 s）；
- 协同维护（联合相对固定）的总延期降低，按规模与 β 分解，与 G4 对照。

**报告规则**：每个假设不论成立与否都写出；3 个种子的结果都列出；看到结果后补做的分析一律标为"探索性"。

## 8. 运行前需要的代码改动（批准后实施并提交，配测试）

1. `g6_attention_policy.py`：另存模仿阶段的最好检查点 `best_bc.pt`，并在 summary 中记录其哈希；其余不变。
2. `maintenance.generator`：加入 G5-T、G5-L 两个网格，种子 1003、1004；测试保证与已有种子不重叠。
3. `attention_policy.rollout`：可选返回每次采样的动作序列；测试保证序列交给 IGA 解码器后得到同样的总延期。
4. `g7`、`g8`：增加 `--grid {g4, g5, g5-large}`，以及 g8 的 `--checkpoint`；默认值保持 G4 原样，不影响 G4 的复现。
5. 新脚本：
   - `g11_g5_seeded_iga.py`：读取 RL 推理输出的序列和耗时，运行 RL + IGA；
   - `g12_g5_summary.py`：汇总曲线、H1–H5、描述性结果。
6. 测试：热启动 IGA 的结果不劣于它的初始序列；新网格可复现；所有输出都过检查器。
