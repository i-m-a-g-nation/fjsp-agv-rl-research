## 1. 模型（已实现，`fjsp_lab.maintenance`）

在原模型基础上，每台机器 i 有 K_i ≥ 1 个互不重叠的维护窗口，每个窗口内必须完整做一次时长 q_i 的维护；
不同机器的 K_i 可以不同。固定模式下每次维护从给定起点 f_ik 开始；联合模式下由算法在窗口内选择。目标仍是最小化总延期。
K_i 全为 1 时就是原模型；已核对重构前后的结果完全一致（见第 6 节）。

生成器 `build_periodic_instance`：

- 作业与交期沿用 G3A，同一 (n, seed) 下完全相同；
- 计划期取基础负荷 W = ⌈Σp / m⌉，周期 T_i = ⌈W / K_i⌉；
- 每次维护时长 q_i = max(1, ⌈αT_i/100⌉)，窗口余量 s_i = min(⌈βT_i/100⌉, T_i − q_i − ⌊25T_i/100⌋)；
- 第 k 个窗口 L_ik = kT_i + ⌊v_ik T_i/100⌋，U_ik = L_ik + q_i + s_i，v_ik ∈ [0, 25]；
- 固定起点 f_ik = L_ik + ⌊s_i/2⌋（窗口中点）。

α 是每个周期中维护所占的比例，所以每台机器的总维护量约为 αW/100，与 K_i 无关。

## 2. 算例网格（测试集）

| 因子 | 水平 |
|---|---|
| 作业数 n | 20, 50, 100 |
| 机器数 m | 2, 4, 8 |
| 维护周期 | `uniform2`（每台 K=2）、`mixed`（K = 1, 2, 3, 1, 2, 3, …） |

| 窗口宽度 β（周期占比 %） | 25, 50 |

共 3 × 3 × 2 × 2 × 2 × 2 × 2 = 288 个案例 × 2 种模式 = 576 个实例。种子与所有训练、验证种子不重叠。

## 3. 方法

| 方法 | 设置 |
|---|---|
| EDD、MDD、ATC（k=1）规则 | 一次构造 |
| 注意力策略（RL，主方法） | 贪心 1 次；采样 4、16、64 次取最好 |
| GA、SA、IGA | 默认参数；按墙钟时间记录 best-so-far 轨迹 |
| CP-SAT | 1 线程，60 s，记录 incumbent 轨迹；只用于构造 best-known，不作主对照 |

**RL 训练**（只用训练集和验证集）：
- 训练集：种子 200000–219999，规模在 n ∈ {20, 50, 100} × m ∈ {2, 4, 8} 中随机抽取，周期方案与 α/β/τ/模式也随机；
- 教师：IGA 5000 次解码；
- 训练流程：先模仿教师，再做 REINFORCE（共享基线）；
- 选模型：只看验证集（种子 210000 起的 300 个实例）上的单次贪心平均值。

预计耗时：教师数据约 1–2 h（8 进程）；训练 ≤ 4 h（RTX 4060）。

## 4. 指标与计时

- 每个实例的 best-known = 所有方法所有运行中的最小值。
- 主要指标：在时间预算 t ∈ {0.05, 0.1, 0.2, 0.5, 1, 2, 5, 10} s 时，相对 best-known 的平均差距 (T − T*) / max(1, T*)，按 n、m 分组。
- 计时口径：
  - 元启发式：单实例、单进程 CPU；
  - RL：单实例，同一实例的多次采样放在一个 GPU 批次里，计入特征计算和环境步进；另报纯 CPU 推理时间作参考。
- 所有排程都过检查器，被拒绝的结果直接终止实验。

## 5. 预先登记的假设

- **H1（RL 的优势区间）**：在 n ≥ 50、t ≤ 0.2 s 时，RL 的平均差距低于同一时刻的 IGA、SA、GA（配对 Wilcoxon，p < 0.01）。
- **H2（预期劣势，如实报告）**：t ≥ 2 s 时，IGA/SA 预计优于 RL。
- **H3（协同维护的作用）**：按维护周期、α、β 分解联合相对固定的总延期降低；用每个实例的 best-known 计算。

H1 不成立也照实写入论文。
