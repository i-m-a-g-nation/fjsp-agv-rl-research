# 毕设论文主线：强化学习为主方法，启发式与精确算法为对照（2026-10-31 修订）

**决定**：2026-10-31 用户把主线改为强化学习（RL），启发式规则、智能优化算法（GA/SA/IGA）和精确方法（CP-SAT、枚举）作为对照。
G4 实验支持这样定位：
- 在 n = 100、0.2–2 s 的时间预算内，RL 显著优于 IGA 和 SA；
- 在小规模或长时间预算下，IGA/SA 更好，论文如实写出。

导师尚未确认这条主线和下面的表述。旧版"IGA 为主"的大纲见 git 历史（提交 `60729a5` 及以前）。

## 一句话定位

> 针对带周期性预防维护时间窗的平行机调度问题，提出一种在元启发式解码器上构造调度的注意力强化学习方法：先模仿 IGA 教师，再用 REINFORCE 微调。
> 它在大规模实例上能在亚秒到秒级时间内给出优于 IGA/SA 的调度，并用于分析生产与维护协同决策的作用。

## 章节安排

1. **绪论**：
   - 背景：维护占用产能、交期压力；
   - 研究现状：维护约束的平行机调度、派工规则、元启发式、深度强化学习调度（构造式策略、注意力网络、模仿学习、POMO 式共享基线）；
   - 研究内容与结构。
2. **问题描述与数学模型**：
   - 假设与符号；
   - 单窗口模型（源自 Lee & Chen 2000）与周期性多窗口扩展；
   - 固定与联合两种维护方式；
   - CP-SAT 模型；NP 难性；
   - 合法性条件（检查器）；
   - 小例子和甘特图。
3. **基于强化学习的调度方法（主方法）**：
   - 3.1 构造式 MDP：在 IGA 解码器上逐个选择"下一个作业"或"某台机器的下一次维护"；机器分配和被迫插入的维护遵循解码器规则；动作掩码保证可行；每步候选约 n + m 个。
   - 3.2 状态特征：20 维逐候选特征，包括完工时间、松弛、MDD/ATC 指标、被迫维护、窗口余量等。
   - 3.3 注意力策略网络：候选之间做自注意力，然后逐个打分。
   - 3.4 训练：先模仿 IGA 教师，再用 REINFORCE（同一实例多次采样的平均值作基线），并说明工程实现（状态批训练、分块重算、bf16）。
   - 3.5 推理：贪心构造与多次采样取最好；CPU 与 GPU 的推理延迟。
4. **对照算法**：
   - 派工规则 EDD、MDD、ATC；
   - GA、SA、IGA（编码、解码、改进点）；
   - CP-SAT 与小规模枚举。

   本章只作简要介绍。
5. **实验与分析**：
   - 5.1 算例与设置：G3A、G4 协议；种子划分；计时口径和硬件；公平性处理（搜索算法在机器空闲时重新计时）。
   - 5.2 模型与算法正确性：CP-SAT 等于枚举；检查器；n = 8 时证得最优（exp_035）。
   - 5.3 训练过程与消融：
     - 模仿阶段 → 强化阶段：验证集 58.53 → 52.17，超过教师 IGA-5000 的 53.88；
     - 采样次数（贪心、4、16、64 次）；
     - CPU 与 GPU 推理。
   - 5.4 质量—时间对比（核心，G4）：
     - 曲线图；
     - 预先登记的 H1（不成立）和 H2（部分成立）；
     - 按规模的分析：n = 100 时在 0.2–2 s 内 RL 优于 IGA 和 SA；n = 50 时与 IGA 持平；n = 20 时 IGA/SA 更好。
   - 5.5 协同维护的作用：
     - G3A：n = 8 证得最优，降低约 30%–56%；
     - G4：n = 20/50/100 分别平均降低 49%/11%/7%，窗口越宽收益越大。
   - 5.6 小规模单窗口问题上的对照（exp_036–040）：IGA 优于早期 RL 策略，用来说明 RL 适用的范围。
6. **结论与展望**：
   - 结论：RL 适用于大规模、需要快速出解的场景；
   - 不足：单一训练种子；n ≥ 50 时缺少最优性参考；只考虑静态问题；
   - 展望：动态重调度、更快的推理、RL 与局部搜索结合。

## 可写的创新点（待导师取舍）

1. **I1：周期性多窗口预防维护模型**。每台机器的窗口数可以不同；对比固定维护与协同优化。
2. **I2：在元启发式解码器上构造调度的 RL 方法**。RL 与 IGA 搜索同一个解空间，候选数随规模线性增长。先模仿 IGA 教师，再强化，结果超过了教师。
3. **I3：质量—时间评价**。按时间预算和规模刻画 RL 与搜索算法各自占优的区间，并预先登记假设、如实报告。
