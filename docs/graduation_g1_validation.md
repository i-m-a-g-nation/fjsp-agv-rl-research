# 毕设 G1：数据、延期与维护合法性验证

2026-10-25 用户明确批准首版 G1，实现范围是数据结构、总延期计算与维护合法性检查。原 Phase2A 加工/动态底座保留；本次没有实现维护优化器，也没有接入 AI 自动生成或自动验收课题的流程。

## 首版范围与接口

同质平行机，每任务一道不可抢占工序，所有任务在0时刻可用；每台机器（含没有生产任务的机器）恰好执行一次必需维护，完整维护区间位于允许窗口内。不同机器维护可同时发生，无共享维修班组。时间和标识使用严格整数，拒绝 bool、浮点与非有限数；加工/维护时长为正，交期和时间非负。

| 接口 | 行为 |
|---|---|
| `ProductionTask` | 不可变的任务标识、加工时间和交期 |
| `MaintenanceRequirement` | 不可变的机器标识、维护时长、完整窗口及可选固定开始时刻 |
| `ParallelMaintenanceInstance` | 复制并按标识排序输入，每个任务和机器标识均唯一且连续；每台机器都需要维护要求 |
| `to_fjsp_instance(data)` | 每个任务映射为一个真实生产工序，所有机器加工时间相同；不添加维护伪工件 |
| `MaintenanceScheduleResult(ScheduleResult)` | 保留原生产记录及 makespan，另存 `maintenance_records`、`total_tardiness` |
| `calculate_total_tardiness(data,result)` | 先检查目标生产实例及原静态合法性，再计算 `sum(max(0,C_j-d_j))`；非法生产结果抛出 ValueError |
| `check_parallel_maintenance_feasibility(result,data,mode=...)` | 返回 `(bool, violations)`，只有生产、维护和汇总延期全部通过才接受 |

所有接口从 `src.graduation` 导出。`mode` 必须显式为 `fixed` 或 `joint`；固定模式要求每台机器预先给定 `fixed_start`，缺失或模式错误属于配置错误，抛出 ValueError。可调模式仍检查全部维护要求，只不要求开始时刻等于固定值。未支持的释放时间、维修班组等构造参数会被拒绝，不会被静默忽略。

度量函数只计算合法生产计划的延期，不单独认证维护合法性。必须另调用领域检查器并确认返回 True，才能将计划视为 G1 合法结果。检查器不会修补记录、更新 makespan 或自动填写延期，缺失/错误的 `total_tardiness` 不能通过。原静态检查器代码未修改，任何拒绝都会使领域结果被拒绝。

## 手算计划及验证证据

以下计划是显式构造的验证输入，来自模型草案中的数学小例。它们用于检查计算与约束；不存在求解器求得这些计划或算法性能比较的含义。

| 输入 | 模式 | 生产区间（任务、机器、起止） | 维护区间 | 独立期望总延期 | 生产 makespan |
|---|---|---|---|---:|---:|
| 单机，p=(2,2)，d=(2,4) | 固定 | J0/M0:2–4；J1/M0:4–6 | M0:0–2 | 4 | 6 |
| 同上 | 可调 | J0/M0:0–2；J1/M0:2–4 | M0:4–6 | 0 | 4 |
| 双机，p=(2,2,2)，d=(2,2,4) | 固定 | J0/M0:2–4；J1/M1:2–4；J2/M0:4–6 | M0、M1:0–2 | 6 | 6 |
| 同上 | 可调 | J0/M0:0–2；J1/M1:0–2；J2/M0:2–4 | M0:4–6；M1:2–4 | 0 | 4 |

所有维护时长均2、窗口均[0,6)，固定开始均0。区间使用半开语义，生产结束恰好等于维护开始、维护结束恰好等于生产开始均合法，维护结束等于窗口上界也合法。生产 makespan 可以小于维护结束时刻，这沿用统一 ScheduleResult 定义，并不改变总延期目标。

可执行原始计划位于 `tests/graduation_helpers.py`；任务、维护和期望数均是字面值，没有调用被测度量计算期望。正例通过与负例拒绝分别断言，不把检查器成功拒绝的计划算作有效调度。

| 负例 | 必须拒绝的原因 |
|---|---|
| 任一机器漏维护，包括闲置机器；重复维护 | 必需维护不满足恰好一次 |
| 维护开始5、结束7，窗口[0,6) | 开始在窗内不足以合法，整个区间必须在窗内 |
| 维护与生产相交、维护时长或 end-start 错误 | 资源占用/时长不合法 |
| 固定模式使用可调方案的维护开始 | 不满足预设 fixed_start |
| 汇总延期为空、伪造、浮点、负数或非有限数 | 未与独立整数重算一致 |
| C=(4,6)、d=(10,0) | 总延期为6，提前完成不能抵消延期 |
| 错误目标实例、漏工序、重复工序、错误 makespan | 原生产约束未通过，不能返回有效指标 |
| 非法机器标识、损坏维护容器或记录、bool/NaN/inf 时间 | 输入诊断并拒绝，不崩溃放行 |
