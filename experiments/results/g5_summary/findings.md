# G5 结论：多种子、模仿消融、RL 热启动 IGA 与规模推广（2026-11-06）

协议：[docs/protocols/g5_supplement_protocol.md](../../../docs/protocols/g5_supplement_protocol.md)（修正 1–8 见其第 9 节）。
数据：G5-T 576 个实例（288 个案例 × 固定/联合，实例种子 1003/1004，训练与 G4 测试都没用过）；
G5-L 128 个实例（n = 200，m ∈ {4, 8}，比训练规模大一倍）。
best-known 取所有方法、所有种子、所有运行中的最小总延期；gap = (T − best-known) / max(1, best-known)。
所有结果目录的 manifest 都记录提交 `7999b06`，`git_dirty` 为 false；汇总本身见 `summary.json`、`hypotheses.csv`、`curves.csv`、`curves.png`。

## 计时与负载

- RL、只模仿：GPU（RTX 4060 Laptop），一次一个实例；另报单线程 CPU（`RL-cpu`）。
- 规则、IGA、SA、CP-SAT（只 n = 20）与 RL + IGA：项目环境，2 个进程。
- 各步依次运行，互不重叠；每步开始前等 CPU < 30%、GPU < 10%、可用内存 ≥ 3 GB 连续 3 次。
  运行中每 10 分钟记录一次：策略推理步骤中 CPU 占用最高 44%；搜索与 RL + IGA 步骤中最高 15%，GPU 为 0。
  可用内存曾在热启动种子 1 运行时降到 1.8 GB（本机另有任务），CPU 占用当时仍低。
- **未核实的一点**：n = 100 上 IGA 的解码速率（未提前到 0 而跑满 10 s 的运行，中位 7.3k 次/s）
  低于 G4 重新计时的结果（11.7k 次/s）。G5 内部的普通 IGA 与三次热启动 IGA 分别在不同时间运行，速率一致（7.2k–7.3k 次/s），
  所以不是某一步单独受到干扰；但速率也随实例与搜索状态变化（n = 20 上普通 IGA 33.6k、热启动 19–20k、G4 18.8k），
  无法据此判断机器状态。整理本文时本机正有其他任务（CPU 57%），没有做空闲机器上的抽样复测。
  如果 IGA 在 G5 中确实偏慢，H1、H5（RL 对 IGA）会偏向 RL；H3、H4（RL + IGA 对 IGA）两边都受同样影响。

## 预先登记的假设

单侧配对 Wilcoxon（去掉差为 0 的配对）；每个种子内对 H1–H5 做 Holm 校正，α = 0.05；3 个种子中至少 2 个满足即成立。
"胜/平/负"是方法相对对照的实例数；均值是该比较中两边的平均 gap（H2 为平均总延期）。

| 假设 | 种子 | 胜/平/负 | 均值（方法 vs 对照） | Holm p | 是否满足 |
|---|---|---|---|---:|---|
| **H1** RL < IGA，G5-T n = 100，t = 1 s | 0 | 54/135/3 | 0.018 vs 0.306 | 1.2e-8 | 是 |
| | 1 | 52/139/1 | 0.033 vs 0.306 | 2.7e-10 | 是 |
| | 2 | 52/135/5 | 0.030 vs 0.306 | 1.4e-7 | 是 |
| **H2** RL 贪心 < 只模仿贪心，G5-T 全部 | 0 | 192/327/57 | 52.72 vs 59.07 | 4.1e-21 | 是 |
| | 1 | 214/322/40 | 52.48 vs 59.14 | 1.3e-28 | 是 |
| | 2 | 212/324/40 | 52.76 vs 59.49 | 2.3e-27 | 是 |
| **H3** RL + IGA < IGA，G5-T 全部，t = 10 s | 0 | 99/456/21 | 0.0073 vs 0.0224 | 1.3e-10 | 是 |
| | 1 | 97/459/20 | 0.0072 vs 0.0224 | 1.3e-11 | 是 |
| | 2 | 98/455/23 | 0.0076 vs 0.0224 | 2.7e-10 | 是 |
| **H4** RL + IGA < IGA，G5-T 全部，t = 1 s | 0 | 118/427/25（570 对） | 0.017 vs 0.133 | 2.1e-15 | 是 |
| | 1 | 112/435/24（571 对） | 0.026 vs 0.133 | 5.0e-12 | 是 |
| | 2 | 112/426/25（563 对） | 0.023 vs 0.135 | 1.6e-12 | 是 |
| **H5** RL < IGA，G5-L，t = 2 s | 0 | 34/89/5 | 0.132 vs 0.117 | 0.0018 | 是 |
| | 1 | 34/88/6 | 0.138 vs 0.117 | 0.0049 | 是 |
| | 2 | 34/83/11 | 0.228 vs 0.117 | 0.17 | **否** |

**结论**：H1–H4 在 3 个种子上都满足，H5 在 2 个种子上满足，按预定规则五个假设都**成立**。需要说明的两点：

- **H4 的覆盖**：RL + IGA 要先做贪心 + 16 次采样，n = 100 上有 1–2% 的实例在 1 s 内还没有解（覆盖 97.7–99.1%）。
  按协议，这些实例不参与配对检验。
- **H5 的均值与检验方向相反**：秩检验显示 RL 更好，但平均 gap 是 RL 更差。原因见下面的探索性分析。

### H5 的探索性分析（看到结果后补做）

- G5-L 很"松"：128 个实例中 91 个 best-known 为 0（τ = 125 的 64 个实例全部为 0）。
  gap 在 best-known 为 0–4 的实例上会被放大：例如 best-known = 1、RL = 4、IGA = 1 时，单个实例的 gap 差就是 3。
  RL 的几次失败都是这类实例（主要是 m = 8、τ = 75），平均 gap 因此被拉高；配对差的中位数为 0。
- 用总延期本身看（t = 2 s），RL 在三个种子上都更好：平均总延期 190.0 / 189.4 / 190.6，IGA 为 208.9。
  RL 胜出的实例上共少 2431 / 2509 / 2371 个单位，失败的实例上共多 15 / 13 / 24 个单位。
- 种子 2 不显著，是因为它在 m = 4 上也有 5 个这样的小失败（其余两个种子为 0–1 个），胜出的实例数相同（34）。
- 所以 H5 的统计结论成立，但应写成"RL 在多数有延期的实例上明显更好，在几乎无延期的实例上偶尔多出几个单位"，
  而不是"平均 gap 更小"。

## 描述性结果

### 质量—时间曲线（3 个种子的平均 gap；括号内为有解比例）

| 规模 | 时间 | EDD | SA | IGA | RL（种子 0/1/2） | RL + IGA（种子 0/1/2） |
|---|---|---:|---:|---:|---|---|
| n = 20 | 0.5 s | 0.656 | **0.013** | 0.025 | 0.051 / 0.071 / 0.047 | 0.020 / 0.031 / 0.023 |
| n = 20 | 10 s | 0.656 | **0.001** | 0.013 | 0.051 / 0.071 / 0.047 | 0.011 / 0.009 / 0.009 |
| n = 50 | 1 s | 0.894 | 0.148 | 0.071 | 0.050 / 0.087 / 0.050 | **0.028 / 0.036 / 0.028** |
| n = 50 | 10 s | 0.894 | **0.008** | 0.025 | 0.050 / 0.086 / 0.050 | 0.009 / 0.011 / 0.012 |
| n = 100 | 1 s | 1.923 | 2.518 | 0.306 | 0.018 / 0.033 / 0.030 | **0.006 / 0.017 / 0.019**（93–97%） |
| n = 100 | 10 s | 1.923 | 0.087 | 0.029 | 0.011 / 0.011 / 0.017 | **0.001 / 0.002 / 0.002** |
| n = 200 | 2 s | 1.494 | 2.356 | 0.117 | 0.132 / 0.138 / 0.228 | 0.087 / 0.022 / 0.116（73–92%） |
| n = 200 | 10 s | 1.494 | 1.209 | 0.078 | 0.110 / 0.108 / 0.109 | **0.027 / 0.044 / 0.014** |

- **与 G4 一致**：RL 的优势在 n = 100、约 0.5–2 s；n = 20 时 SA、IGA 一直更好，RL 停在 gap ≈ 0.05–0.07。
- **RL + IGA**：n ≥ 50 时，1 s 以后在所有方法中最好；n = 100、10 s 时 gap 为 0.001–0.002，IGA 为 0.029。
  n = 20 时只比纯 IGA 稍好，仍不如 SA（10 s：0.009–0.011 vs 0.001）。
- **n = 200**：SA 的降温参数不随规模调整，10 s 内几乎没有改进（gap 1.2）；IGA 仍有效。
  RL 的单次 GPU 贪心推理中位 0.56 s（CPU 0.66 s），1 s 之前没有解；采样 64 次累计约 4 s。
  RL + IGA 的推理部分（贪心 + 16 次采样）中位 1.9 s，所以 2 s 时只有 73–92% 的实例有解。
- 图 `curves.png` 画的是 3 个种子的平均曲线（只画有解比例为 100% 的点）；协议原定 3 个种子分开画，分种子的数值在 `curves.csv`。

### 种子之间的差异

- RL：全体 G5-T 上 1 s 时 gap 为 0.040–0.064，10 s 时 0.037–0.056。种子 1 在 n = 20、50 上明显较差
  （n = 50：0.086 vs 0.050），在 n = 100 上与其他种子相当。种子 1 的验证集结果却是三者中第二好，验证集排名不能预测测试集排名。
- RL + IGA：10 s 时三个种子的全体 gap 为 0.0072–0.0076，几乎没有差别；搜索把模型之间的差异抹平了。

## 局限

- n ≥ 50 时没有可证明的最优解，gap 是相对"已找到的最好解"；best-known 现在包含 RL + IGA，
  所以 G5 的 gap 比 G4 的同名数值更大，不能直接与 G4 的表格比较。
- 平均 gap 会被 best-known 很小的实例放大（H5 就是一例）；配对检验基于秩，不受此影响。
- 搜索方法只用种子 0；IGA 解码速率与 G4 的差异未在空闲机器上复测（见"计时与负载"）。
- 所有计时都在一台笔记本上；RL 用 GPU、搜索用 CPU，两者的时间可比性依赖于"本机无其他负载"。
